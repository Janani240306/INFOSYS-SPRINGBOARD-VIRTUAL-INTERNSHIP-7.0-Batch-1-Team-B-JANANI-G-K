# 📊 Cyber Threat Analytics Platform with Incident Visualization System 

## 🚀 Project Overview

This project was completed as part of our internship with **Infosys Springboard Virtual Internship 7.0**.

**Cyber Threat Analytics Platform with Incident Visualization System ** is an interactive **Business Intelligence and cybersecurity analytics project** designed to analyze global cybersecurity incidents and transform raw cybersecurity data into meaningful insights through interactive dashboards.The project uses **Microsoft Power BI, Power Query, and DAX** to transform the **Global Cybersecurity Threats (2015–2024)** dataset into meaningful insights and an easy-to-understand visual experience.

The project demonstrates how **Business Intelligence and data visualization** can be used to analyze real-world cybersecurity problems by providing data-driven insights, interactive visualizations, and meaningful analysis.

## 🚀 Key Features

### 📊 Interactive Cybersecurity Dashboards
Provides seven interactive Power BI dashboards for analyzing cybersecurity incidents from different perspectives.

### 🔍 Cyber Attack Analysis
Analyzes attack types, attack sources, trends, risk levels, industries, and countries.

### 🧠 Vulnerability & Defense Analysis
Analyzes major vulnerabilities and the distribution of defense mechanisms used against cyber threats.

### ⚙️ Risk & Financial Impact Analysis
Examines high-risk incidents, financial losses, affected users, and resolution time.

### 📈 Pattern & Trend Analysis
Identifies cybersecurity patterns and trends across years, countries, attack types, and risk levels.



## 🛠️ Tools & Technologies

- **Microsoft Power BI:** Interactive dashboard development and data visualization
- **Power Query:** Data cleaning, transformation, and preprocessing
- **DAX:** Creation of measures and KPIs for analysis
- **Kaggle:** Source of the Global Cybersecurity Threats dataset
- **GitHub / GitLab:** Project repository and documentation



## 📊 Project Workflow

### Data Collection
Collected the **Global Cybersecurity Threats (2015–2024)** dataset from Kaggle.

### Data Cleaning & Preprocessing
Cleaned and transformed the dataset using Power Query by removing duplicates, correcting data types, standardizing values, and preparing the data for analysis.

### Data Analysis
Analyzed cybersecurity incidents based on attack type, attack source, country, industry, vulnerability, risk level, financial loss, affected users, and resolution time.

### Visualization / Development
Developed seven interactive Power BI dashboards using KPIs, bar charts, line charts, donut charts, treemaps, maps, tables, and slicers.

### Insights & Interpretation
Analyzed the dashboards to identify important cybersecurity patterns, risk levels, financial impacts, vulnerabilities, defense mechanisms, and attack trends.



## 🎯 Objectives

- To collect and analyze cybersecurity incident data from multiple countries and industries.
